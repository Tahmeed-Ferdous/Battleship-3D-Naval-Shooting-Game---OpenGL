Battleship: A 3D Naval Combat Game
Project Overview
Battleship is a 3D action game where players control a battleship on an ocean grid, shooting missiles at pursuing enemy ships to survive waves and score points. Themed around naval battles, it uses simple geometric models for ships and a checkered blue grid for water, with colored boundaries. Core gameplay involves movement, shooting, and collecting items while avoiding enemy contact.
Gameplay Mechanics

Objective: Destroy enemies with missiles, collect power-ups, and survive waves. Game over on zero life or excessive misses.
Controls:
Move: W/S (forward/back).
Rotate: A/D.
Shoot: Left mouse.
Camera: Right mouse toggle (first/third-person); arrows for adjustments.
Cheat: C.
Pause: P.
Reset: R.
Difficulty: Select at start (1-3 for levels).


Key Features

Ships Shooting Missiles: Fire directional missiles; hits destroy enemies, misses penalized.
Ship Movement: Navigate grid with rotation and bounded movement.
Cheat Mode: Auto-aim, auto-fire, ignore miss penalties.
Camera Control: Switch views; adjust angle/height.
Bonus Points in Random Places: Collect for extra score.
Lifeline Points in Random Places: Collect to restore life.
Difficulty Option: Adjust enemy speed, spawns, etc.
Pause/Resume: Freeze game with overlay.
Temporary Invincibility Power-Up: Short shield from damage; ship flashes.
High Score Tracking: Save and display top scores.
Enemy Types Variation: Fast/slow ships with unique behaviors.
Achievement Notifications: Pop-ups for milestones like "10 Kills."
